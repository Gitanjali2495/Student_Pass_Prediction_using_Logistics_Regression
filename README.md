# Student Pass Prediction Using Logistic Regression

## Project Overview
This project uses Machine Learning to predict whether a student will pass or fail based on study hours, attendance percentage and previous examination marks.

## Algorithm Used
- Logistic Regression
- Binary Classification

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Dataset Features
- Study_Hours
- Attendance
- Previous_Marks
- Result (0 = Fail, 1 = Pass)

## Project Workflow
1. Dataset Creation
2. Data Exploration
3. Data Cleaning
4. Data Visualization
5. Feature Selection
6. Train-Test Split
7. Logistic Regression Model Training
8. Model Prediction
9. Model Evaluation
10. New Student Prediction
11. Model Saving

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC Score

## How to Run
1. Download the repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Install the required libraries.
4. Execute the notebook cells in order.
